How it works

Lines are parsed into auth events, aggregated per source IP into behavioural features, and scored by a logistic-regression model trained on a synthetic corpus of legit, fumbling, brute-force, stuffing and low-and-slow sessions (loading…). The same model serves from a FastAPI backend on AWS Lambda + DynamoDB; set an API URL above to use it. Your logs never leave the browser in in-browser mode.
